# GitHub Research Profile Analyzer

A lightweight Python tool that analyzes public GitHub developer profiles and repositories using the **GitHub REST API**.

## Features

- Retrieve public GitHub profile information
- Analyze public repositories
- Count programming languages
- Calculate total repository stars and forks
- Display recently updated repositories
- Work directly with the GitHub REST API
